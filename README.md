# Ferramentas gratuitas e soluções digitais

Este repositório reúne aplicações web e materiais de apoio. Para conhecer os recursos atualmente verificados e publicados:

## Gestão Simples para Autônomos

- [Página do Kit Gestão Simples](https://ruiveira.github.io/solucoes-rapidas/marketing/)
- [Calculadora gratuita de preço de serviços](https://ruiveira.github.io/solucoes-rapidas/marketing/calculadora.html)
- [Guia de controle de recebimentos](https://ruiveira.github.io/solucoes-rapidas/marketing/recebimentos.html)
- [Guia de propostas e atendimento](https://ruiveira.github.io/solucoes-rapidas/marketing/propostas.html)

O kit contém planilha Excel, um guia PDF e 20 prompts de organização. **A venda ainda não está ativa**; não há link de checkout verificado ou oferta de compra disponível na página.

## GoMove

- [Página de apresentação e situação de pré-lançamento](https://ruiveira.github.io/solucoes-rapidas/gomove/)
- [Aplicativo web GoMove](https://go-move-ride.base44.app/)

GoMove ainda exige comprovação de autorização operacional e homologação de pagamento, reembolso e repasse. A existência do app web não comprova funcionamento comercial.

## Uso responsável

Os exemplos de organização e cálculo são informativos, não consultoria contábil, promessa de receita ou garantia de resultados. Não envie CPF, documentos pessoais, senhas, chaves privadas nem pagamentos por links não confirmados.

## Operação

- A publicação web usa GitHub Pages e um fluxo GitHub Actions para manter as páginas no ar após atualização.
- A verificação automatizada de integridade e sitemap é configurada em `.github/workflows/marketing-quality.yml`.
- Textos para divulgar exclusivamente em contas autorizadas: [campanha orgânica](marketing/POSTAGENS_PRONTAS.md).

Projetos antigos no repositório podem estar em manutenção e não devem ser tratados como produtos ativos sem confirmação individual das funcionalidades e condições.
